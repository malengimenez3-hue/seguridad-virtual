# Seguridad virtual

Sitio web educativo para una muestra escolar sobre amenazas digitales.

## Cómo abrirlo
1. Descargá o cloná este repositorio.
2. Mantené todos los archivos en la misma carpeta.
3. Abrí `index (3).html` en un navegador.

## Archivos
- `index (3).html`: portada y menú de temas.
- `peligros_wifi.html`: riesgos de las redes Wi-Fi públicas.
- `watsapp_robo.html`: robo de identidad por WhatsApp.
- `SS7_attack.html`: ataques y vulnerabilidades relacionadas con SS7.
- `Estafas-digitales.html`: phishing, smishing, vishing y spoofing.
- `styles2.css`: diseño visual compartido y adaptable a celulares, tablets y computadoras.

El diseño utiliza Google Fonts, por lo que la tipografía personalizada requiere conexión a internet. El contenido principal funciona sin JavaScript.
